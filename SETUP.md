# Mental Health Platform — Setup Guide

This project has three services that must all be running at the same time:

| Service | Tech | Port |
|---|---|---|
| Backend API | Node.js + Express + MongoDB | 3001 |
| Frontend | React + Vite | 5173 |
| AI Service | Python + Flask | 5001 |

---

## Prerequisites

Install the following before starting:

- **Node.js** v18 or higher — https://nodejs.org
- **Python** 3.9 or higher — https://python.org
- **MongoDB** (Community Edition) — https://www.mongodb.com/try/download/community
  - Make sure MongoDB is running locally on port `27017`
- **Git** — https://git-scm.com

---

## 1. Clone the Repository

```bash
git clone <your-repo-url>
cd "Mental Health Platform"
```

---

## 2. Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the `backend/` folder:

```env
PORT=3001
DATABASE_URL="mongodb://localhost:27017/mhp_db"
JWT_SECRET="your_jwt_secret_here"
JWT_REFRESH_SECRET="your_refresh_secret_here"
AI_SERVICE_URL="http://localhost:5001"
FRONTEND_URL="http://localhost:5173"

# Zoom API (Server-to-Server OAuth App)
ZOOM_ACCOUNT_ID="your_zoom_account_id"
ZOOM_CLIENT_ID="your_zoom_client_id"
ZOOM_CLIENT_SECRET="your_zoom_client_secret"
```

**Getting Zoom credentials:**
1. Go to https://marketplace.zoom.us
2. Click **Develop → Build App**
3. Choose **Server-to-Server OAuth**
4. Copy Account ID, Client ID, and Client Secret into the `.env`

Start the backend:

```bash
npm run dev
```

The API will be available at `http://localhost:3001`.

---

## 3. AI Service Setup

```bash
cd ai-service
```

Create a virtual environment (recommended):

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Train the model (required before first run):

```bash
python train_model.py
```

This reads `Combined Data.csv`, trains the classifier, and saves three files to the `models/` folder. It only needs to be run once.

Start the AI service:

```bash
python app.py
```

The AI service will be available at `http://localhost:5001`.

---

## 4. Frontend Setup

```bash
cd frontend
npm install
```

Create a `.env` file inside the `frontend/` folder:

```env
VITE_API_URL=http://localhost:3001/api
VITE_AI_URL=http://localhost:5001
```

Start the frontend:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Running All Three Services

You need **three separate terminals** open at the same time:

**Terminal 1 — Backend**
```bash
cd backend
npm run dev
```

**Terminal 2 — AI Service**
```bash
cd ai-service
venv\Scripts\activate   # or: source venv/bin/activate on Mac/Linux
python app.py
```

**Terminal 3 — Frontend**
```bash
cd frontend
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Common Issues

**MongoDB not connecting**
- Make sure MongoDB is installed and the service is running
- On Windows: search for "Services" → find "MongoDB" → Start
- On Mac: `brew services start mongodb-community`

**AI model not found error**
- Run `python train_model.py` inside `ai-service/` before starting `app.py`

**Port already in use**
- Check if another process is using ports 3001, 5001, or 5173
- Change the port in the relevant `.env` file if needed

**Zoom meetings show "Invalid Meeting ID"**
- Make sure your Zoom Server-to-Server OAuth app credentials are correct in `backend/.env`
- The Zoom app must have the `meeting:write` scope enabled

**eSewa payment (testing)**
- The platform uses eSewa's sandbox environment (`rc-epay.esewa.com.np`)
- Use eSewa test credentials to simulate payments — do not use real eSewa accounts in development
